# SURE Content Studio • staff guide
Managed by StarrTree. Open the company's staging bookmark in Pages CMS. Sign in with your invited work email and verification code. Confirm **CACthermo / SureMechanical / content-staging** before every editing session. If you see main or a setup prompt, stop and contact Max Starr.

## Update a project

1. Select **Projects**. Search for the project name, customer, or job number. Open the matching record and confirm its name and customer.
2. Change the approved text. Keep the stable ID. The customer display line appears on the website. Additional customer names help people search. Leave unconfirmed details blank.
3. To add a photograph, open **Project gallery photos → Add item**. Use the photo upload button to choose a JPG, PNG or WebP. The field starts in **uploads**. To reuse an existing photo of this same job, use the folder picker and browse **2026** or **uploads**. In the separate **Project Photos** library, enter **uploads** before dragging or selecting files. Wait for upload confirmation, then attach it from the project.
4. Describe what someone can see, for example “Rooftop air handling unit at the west entrance.” Add a caption if there is useful public context. Drag rows into the intended order. The first photo is the card cover. To replace a picture, upload a fresh one to the row. Removing the row detaches it from that project.
5. Save the project. An uploaded file alone does not update a gallery. Check the saved record, then give the project name and requested change to Max Starr.

## Create, feature or withdraw

Select **Projects → New**. Choose a unique short ID of lowercase letters, numbers and hyphens. Enter an approved name, customer if known, and display order. Leave the job number blank unless supplied. The website can display a project before it has photographs.

A new record starts as a draft. Switch **Include on the website after review** on when it is ready for review. Turn it off to withdraw an existing record in the next approved release. Lower numbers appear first in the directory. Card views prioritize featured projects, then projects with photos, then display order. The regular view shows the first six cards until expanded.

## Company Information

Edit the matching named field and save. A blank public phone or address is hidden. Only enter an approved company phone or office location. Send requests about recipients, navigation, security or layout to Max Starr.

## If something looks wrong

| What you see | What to do |
|---|---|
| Required field or red message | Read the message, fix that field and save again. |
| Photo rejected during review | Use a still JPG, PNG or WebP no larger than 10 MB. Each side must be 160–10,000 pixels and the image at most 40 megapixels. Export a smaller version from Photos and upload it under uploads. |
| Missing or duplicate photo | Verify the project and select the correct image. A photo can belong to only one project. Leave it blank if its identity is uncertain. |
| Saved but absent from live website | Check the visibility switch, staging branch and reviewer. The reviewer must approve and publish the change. |
| Wrong job or accidental save | Tell the reviewer immediately. Give the project name and what changed. Max can restore an earlier version. |
| Private material | Keep it out of the editor. All branches and source images in this repository are public, including drafts. |

The project, general and HR buttons on the public site lead to their existing forms. Editing office copy does not change which inbox receives a message.
